# 3D Prints – אתר חדש

אתר תדמית וחנות ל־3D Prints, סטודיו להדפסת תלת־ממד. דף אחד (`index.html`) בלי שלב בנייה, עם התמונות בתיקייה `assets/`.

## מה יש באתר
- הדמיה חיה של הדפסה, שכבה אחרי שכבה (Canvas)
- קטגוריות, חנות עם סינון וסל קניות (הסל נשמר בדפדפן)
- תהליך הזמנה אישית, מדריך חומרים, טופס הזמנה ושאלות נפוצות
- מצב בהיר וכהה, מותאם לנייד ותומך בהפחתת תנועה

## עריכה
- מוצרים ומחירים: המערך `PRODUCTS` בתוך `index.html`
- צבעים וגופנים: המשתנים בבלוק `:root` בראש ה־CSS

## לפני שעולים לאוויר
- **טופס ההזמנה** עדיין לא שולח לשום מקום. צריך לחבר אותו (למשל Formspree, וואטסאפ או מייל) בפונקציה של `form.addEventListener('submit', …)`.
- **התשלום** לא מחובר. כפתור "מעבר לתשלום" מציג הודעה בלבד. צריך לחבר ספק סליקה.
