# עוגן לווינדוס 11

גרסת Windows של עוגן (האפליקציה לאנדרואיד נמצאת בענף `ccr-9d5f6a10-vbri4e`).
אותו רעיון בדיוק: **כל מה שמחמיר נכנס מיד, וכל מה שמקל מחכה 24 שעות.**

## הורדה והתקנה

1. מורידים את [`release/windows/Ogen.exe`](release/windows/Ogen.exe). זה קובץ אחד, ולא צריך להתקין .NET.
2. מפעילים אותו. Windows SmartScreen עלול להזהיר כי הקובץ לא חתום: לוחצים **"מידע נוסף" ← "הפעל בכל זאת"**.
3. עוגן מעתיק את עצמו ל-`%LOCALAPPDATA%\Programs\Ogen`, נפתח עם Windows ויושב באזור ההודעות (ליד השעון).

לא צריך הרשאות מנהל.

## מה יש בפנים

| | |
|---|---|
| **זמן מסך ליום** | הזמן יורד רק כשמשתמשים במחשב (אחרי 5 דקות בלי עכבר ומקלדת הספירה נעצרת). כשנשארות 5 דקות ודקה אחת מקבלים התראה. כשהזמן נגמר, כל חלון שאינו "תמיד פתוח" ממוזער ומכוסה במסך חסימה עד חצות. שום דבר לא נסגר ושום עבודה לא הולכת לאיבוד. |
| **רשתות ויוטיוב** | חסומים תמיד, גם בלי מגבלה יומית: יוטיוב, אינסטגרם, טיקטוק, פייסבוק, X, רדיט, נטפליקס, טוויץ׳ ועוד. בכל דפדפן (Chrome, Edge, Firefox, Brave, Opera...) הלשונית נסגרת מיד. גם אפליקציות החנות שלהם נחסמות. |
| **תמיד פתוח** | אפליקציות שלא נספרות ונשארות פתוחות גם כשהזמן נגמר. שולחן העבודה, סייר הקבצים, ההגדרות ו"קישור לטלפון" (שיחות והודעות) תמיד פתוחים. |
| **הגנה** | בזמן שמשהו מוגן, מנהל המשימות, מתזמן המשימות ועורך הרישום נסגרים. משימה מתוזמנת מפעילה את עוגן מחדש תוך דקה אם הוא נסגר. שינוי שעון המחשב לא עוזר: עוגן משתמש בשעון "מהימן" שמבוסס על הזמן מאז ההפעלה. |

אפשר לצאת מעוגן או להסיר אותו (בתפריט של האייקון ליד השעון) רק כשאין זמן מסך פעיל וחסימת הרשתות כבויה.

## מגבלות ידועות

- עוגן הוא כלי התחייבות ולא כלי אבטחה. משתמש עם הרשאות מנהל שמתעקש יכול לעקוף אותו, למשל דרך שורת הפקודה.
- זיהוי אתר בדפדפן מתבסס על כותרת הלשונית (למשל "... - YouTube"). אתר שמסתיר את שמו מהכותרת לא ייתפס.

## מבנה

```
windows/
  Ogen.Core/   הלוגיקה (מדיניות 24 שעות, שעון מהימן, כללי חסימה) בלי תלות ב-Windows
  Ogen.Tests/  בדיקות יחידה (xUnit)
  Ogen/        האפליקציה: WinForms, אייקון במגש, שומר (guard), מסך חסימה
  ci/e2e.ps1   בדיקת קצה-לקצה על Windows אמיתי ב-CI
release/windows/
  Ogen.exe     נבנה אוטומטית ב-GitHub Actions
  shots/       צילומי מסך מה-CI
```

בנייה מקומית (גם מלינוקס):

```bash
dotnet test windows/Ogen.Tests
```

```bash
dotnet publish windows/Ogen/Ogen.csproj -c Release -o out
```
